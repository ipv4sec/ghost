# Ghost 功能列表

115 网盘第三方 Android 客户端（Flutter），基于 115 生活开放平台（open.115.com）
接口构建。账号授权凭证与本地设置仅保存在本机。

## 登录与账号

- 扫码授权登录（开放平台设备码 + PKCE）：取二维码 → 115 App 扫码确认 →
  换取 token；二维码失效自动提示刷新，可重试
- token 持久化保存本机；access token 过期自动刷新（单飞锁，并发请求只触发
  一次刷新）；refresh token 终态失效自动清除凭证回到登录页
- Android 上网络请求走 Cronet（Chromium 网络栈，经 GMS 动态下发）：
  115 云盾 WAF 会按 TLS 指纹拦截 Dart HTTP，Cronet 不可用时自动回退 dart:io
- 退出登录：确认弹框后清除授权凭证

## 文件浏览（主页）

- 目录导航：点文件夹进入、返回手势回上级；主页根目录返回手势
  为「再划一次退出」（2 秒内第二次才退出，屏幕正中提示）
- 列表分页：每页 50 条，滚动到底自动加载下一页（按 fid 去重，
  防页边界位移导致重复）
- 下拉刷新；同一目录刷新合并去抖（连点只发一轮请求），
  目录/排序切换时旧请求结果自动作废
- 排序（顶栏三个点菜单）：按名称 / 大小 / 上传时间 / 修改时间；
  点当前项切换升/降序；全局生效并持久化，文件页即时重拉
- 本地列表过滤：小于 512 MB 的文件不显示（文件夹不受限，见 AppConfig）；
  .iso 后缀文件不显示（不分大小写，文件夹不受限）
- 空文件夹处理：列表里自动隐藏（查详情按 count 判断，会话级缓存，
  剔除带淡出折叠动画）；点按先拉该目录列表走同链过滤，无可见文件
  直接 toast「无文件」不进入（内容全被过滤的「本地空」目录同样命中）；
  推入的文件页（如云下载保存位置）首屏为空自动弹回并提示
- 名字屏蔽词过滤：命中屏蔽词（大小写不敏感）的文件/文件夹不显示
- 长按行菜单：剪切（到目标目录点粘贴栏完成移动）/ 删除（确认后移入
  115 回收站，行内收起动画）/ 重命名
- 点按行为：文件夹进入（空目录直接提示不进入）；视频进播放器；
  其他文件弹详情面板（类型/大小/时间，视频带播放按钮）
- 加密文件夹：提示使用 115 官方 App 查看
- 顶栏：单击进云下载页，双击进搜索页；汉堡按钮侧滑打开「我的」抽屉
- 列表/网格双视图（网格切换入口暂时隐藏，代码保留）
- 新建文件夹 FAB（暂时隐藏，代码保留）
- 顶栏路径行 + 统计行（暂时隐藏，代码保留）

## 全盘搜索

- 关键词全盘搜索：输入 500ms 防抖自动搜索，回车提交并记入历史
- 筛选 chips：全部 | 文件 | 文件夹 | 音频 | 图片 | 视频（客户端过滤）
- 最近搜索历史：最多 10 条，点击回填立即搜索，可一键清空（仅本机保存）
- 搜索结果屏蔽词过滤；结果行与文件页同款，视频可直接播放
- 空态区分：未找到 / 当前筛选类型无结果 / 结果均被屏蔽词过滤

## 视频在线播放（全屏沉浸式）

- 播放 115 转码的 m3u8（地址无扩展名，显式按 HLS 解析）；
  进入直接选最高清晰度，失败自动降档重试（档间强制间隔，
  避免触发视频网关 WAF 频控）
- 续播与进度记忆：进入时读上次进度；暂停/退出时上报，
  播完自动标记看完（失败静默）
- 播放失败时对播放地址做 HTTP 探测（状态码/Content-Type/响应摘要），
  报错文案含诊断信息并支持重试
- 手势（整屏生效，含黑边区域）：
  - 屏幕左半边上下滑调亮度（最低 10%）
  - 屏幕右半边上下滑调音量（可到静音）
  - 左右滑快退/快进（5 秒一档，单次手势累计最多 5 分钟）
- 方向锁（右下角）：进入强制双横屏并锁定；解锁后完全跟随手机物理方向
  （竖过来变竖屏播放），再点固定当前方向；退出恢复跟随系统
- 倍速菜单（右上角透明入口，点区域唤出）：1.0 / 1.5 / 3.0 / 5.0 倍速
- 细进度条（2px）：点按/拖动跟手 seek；seek 期间播放态冻结，
  防止 buffering 造成播放按钮闪烁
- 控件 2 秒无操作自动隐藏；暂停期间常驻；播放中保持屏幕常亮
  （暂停时解除，允许系统熄屏省电）

## 云下载（离线任务）

- 磁力链接唤起：系统点击 magnet: 链接可直接打开本应用（冷启动带入 +
  热启动点击都支持），进入添加落地页确认（可复制链接）
- 提交云下载：支持 HTTP(S)/FTP/磁力/电驴链接（换行分隔可批量）；
  成功后直接跳转任务列表
- 任务列表：默认显示 5 条，「加载更多」逐次 +5；有分配中/下载中任务时
  每秒轮询刷新（页面不在最前不轮询，避免挤占请求队列），
  全部结束自动停止
- 任务行：状态圆底图标（下载中/完成/失败，与文件列表同风格）；
  下载中副标题直接带百分比（无进度条），日期·大小与文件页一致；
  卡住不动（含 0%）超 1 分钟按失败态展示（仅改显示，恢复前进翻回）；
  无名任务标题显示磁链摘要（仅 btih）
- 左滑删除任务（接口成功才收起）；点击已完成任务跳转其保存位置
- 云下载后自动打开（设置开关）：从磁力页提交后任务页等任务完成，
  自动打开其保存位置；任务失败/被删则不再等待

## 我的（侧边抽屉）

- 用户信息头部：头像、用户名、年度会员认证图标、会员服务到期时间
  （中文年月日）、存储使用方块点阵（行尾与到期行对齐）
- 菜单：设置、关于；底部退出（带确认）
- 未登录时经登录页扫码进入

## 设置

- 主题配色：flex_color_scheme 内置方案列表（约 50 套，参考 varus）；
  点击弹窗选择（方案名 + 4 色圆点预览 + 选中勾），切换全局即时生效，
  持久化保存（ghost.scheme）
- 界面字体：Montserrat（中文回退微软正黑体）/ 系统字体，弹窗二选一，
  全局即时生效，持久化保存（ghost.font）
- 云下载后自动打开：开关（ghost.auto_open），见云下载一节
- AppID 本地覆盖：留空使用内置 client_id，仅本机保存
- 名字屏蔽词：换行/英文逗号/中文逗号分隔输入，大小写不敏感去重，
  对文件列表与搜索结果全局生效（仅本机保存）
- 排序设置已迁至主页顶栏三个点菜单

## 底层与网络（lib/network、lib/session）

- Open115Client：业务接口全局限速（串行队列 + 最小间隔 500ms，
  防平台频率控制 405）；405 自动冷却退避重试一次
- 读接口 2 秒结果缓存 + 在途去重（连点刷新只发一次真实请求）；
  写操作成功后整体失效读缓存
- 40140125/40140126 自动单飞刷新 token 并重放请求
- API 与视频流统一 User-Agent，避免 WAF 按请求特征拦截
- 扫码长轮询 35 秒超时（对齐服务端 30 秒长轮询）
