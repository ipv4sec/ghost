# Ghost 功能列表

115 网盘第三方 Android 客户端（Flutter），基于 115 生活开放平台（open.115.com）
接口构建。同一 APK 手机 / Android TV 双端运行（见「电视（Android TV）适配」）。
账号授权凭证与本地设置保存在本机，并自动明文备份到外部存储根目录隐藏文件
.ghost.json，卸载重装后可自动恢复登录与设置（见「备份与恢复」）。

## 电视（Android TV）适配

同一 APK 手机/电视双端运行（Sony 电视 Android 10 验证）：手机端全部
触摸行为保留不变，电视端叠加遥控器（D-pad：上下左右 + OK + 返回）交互。

- 平台声明：manifest 声明 leanback 与「无触摸屏」均为非必需（单一 APK
  两端可装），LEANBACK_LAUNCHER 让应用出现在电视桌面；TV banner 为
  电视桌面横幅图标
- 电视判定：MainActivity 用 UiModeManager 判定（currentModeType 为
  TELEVISION），Dart 侧启动时读一次（先于首帧，判定失败按手机处理）；
  电视上全局文字放大 1.2 倍（3 米观看距离，只缩放文字不改布局）
- 电视首页：Jellyfin 风格深色媒体中心（配色页面自包含，不随配色方案
  变）：顶栏 = 时钟 · 设置齿轮（无搜索框、无头像；电视端不提供抽屉/
  退出入口，凭证失效自动回登录页）；页顶路径面包屑（「首页」，最左侧）；
  内容 = 上下两个区块、均无区块标题——「文件夹」区（上，4 列网格卡片：
  圆角深卡 + 文件夹图标 + 名称）、
  「文件」区（下，5 列竖卡网格：独立文件卡组件——中间圆角底本地图标
  （视频 = 视频图标、其余 = 类型图标，不走网络）、名称两行居中、分隔线、
  底部尺寸 + 扩展名角标；卡片与图标均比文件夹卡小一号），空区块自动
  消失；根目录一次请求即出全部内容。
  D-pad 聚焦卡蓝描边 + 光晕（描边卡内绘制、四边统一）+ 聚焦居中滚动
  跟随；初始聚焦首卡；点文件夹进电视文件夹页（同款深色网格），点视频
  直接进播放页，加密文件夹提示用官方 App，其他类型 toast；返回键双击
  退出；整页缩放系数 0.85（tv_cards.dart 的 kTvScale 一处可调）；
  手机端主页仍是原文件页，一行未改
- 焦点系统：全局 ThemeData.focusColor 统一焦点高亮（主题色 14% 透明
  度），InkWell/IconButton 聚焦自动亮起；手机触摸模式不显示焦点高亮，
  观感不变
- 登录页：二维码 200 与手机端一致；二维码失效/出错时重试按钮出现
  即聚焦，遥控器 OK 直接重试
- 文件页：进入目录/回上级自动聚焦首行
  （一次性：刷新/加载更多不把焦点拽回首行）；长按行出「保存到
  屏蔽列表」弹窗，遥控器 OK 键长按唤出、保存按钮自动聚焦
- 播放页：遥控器交互见「视频在线播放」章节（控件隐藏时方向键 seek、
  OK 唤控件聚焦播放键、进度条聚焦 ±5 秒等）
- 我的：退出登录确认弹窗默认聚焦「取消」，防遥控器 OK 误触退出
- 设置页：配色/字体弹窗打开自动聚焦当前选中项，方向键就近切换
- 安装：手机 APK 直接装到电视即可，无需单独构建版本

## 登录与账号

- 扫码授权登录（开放平台设备码 + PKCE）：取二维码 → 115 App 扫码确认 →
  换取 token；二维码失效自动提示刷新，可重试
- token 持久化保存本机；access token 过期自动刷新（单飞锁，并发请求只触发
  一次刷新）；每次写入 token（含刷新轮换）同步重写备份文件，保证备份内
  refresh token 始终最新；refresh token 终态失效自动清除凭证回到登录页
- Android 上网络请求走 Cronet（Chromium 网络栈，经 GMS 动态下发）：
  115 云盾 WAF 会按 TLS 指纹拦截 Dart HTTP，Cronet 不可用时自动回退 dart:io
- 退出登录：确认弹框后清除授权凭证并删除备份文件（防止下次启动把已作废
  凭证恢复回来）

## 备份与恢复（卸载不丢）

- 备份文件：`<外部存储根>/.ghost.json`（隐藏文件，如 /storage/emulated/0/.ghost.json），
  明文 JSON（version/saved_at/token/prefs 四字段），不随应用卸载清除；
  prefs 白名单 = 屏蔽词、排序、主题配色、界面字体、网格视图
- 写入时机：登录成功、每次 token 刷新（refresh token 轮换制，必须同步）、
  任一设置变更（800ms 防抖合并）；tmp+rename 原子写；未登录不写文件
- 恢复时机：启动时本地无 token 且备份存在 → 静默写回 prefs（先于主题与
  会话初始化，下游无感）；恢复后靠现有刷新链自愈——token 过期自动刷新，
  refresh token 已作废则清凭证删备份回登录页
- 权限：API 24-29 运行时读写权限 + requestLegacyExternalStorage（索尼电视
  Android 10 走此路径，每 install 弹一次）；API 30+ 「所有文件访问」设置页
  授权（MANAGE_EXTERNAL_STORAGE），登录页一次性提示 + 授权返回 live-apply
  免重启；权限经 MainActivity 'ghost/backup' 通道（零第三方依赖）
- 设置页「备份与恢复」区块：状态（路径/最近备份时间/权限）、立即备份、
  删除备份、去授权；App 退后台时 flush 防抖中的待写备份
- 明文风险（已知取舍）：能读取外部存储的应用/人可获取凭证；
  多设备同账号共用备份文件会互相覆盖，恢复后走自愈链

## 文件浏览（主页）

- 电视端进文件夹 = 深色 4 列卡片网格（与主页同款卡片：子文件夹横卡在上、
  文件竖卡在下；长按/遥控器 OK 长按仍可加屏蔽词；接近底部自动翻页）；
  每页顶部路径面包屑（首页 › 一级 › …，祖先段灰色可点跳回、当前段白色
  加粗；主页固定显示「首页」；不进遥控器焦点遍历，回上级仍用返回键）；
  手机端 FilesPage 保持浅色列表/网格双视图不变
- 目录导航：点文件夹进入、返回手势回上级；主页根目录返回手势
  为「再按一次返回退出应用」（2 秒内第二次才退出，屏幕正中提示，
  文案对侧滑返回与遥控器返回键通用）
- 列表分页：每页 50 条，滚动到底自动加载下一页（按 fid 去重，
  防页边界位移导致重复）
- 下拉刷新；同一目录刷新合并去抖
  （连点只发一轮请求），目录切换时旧请求结果自动作废
- 本地列表过滤：小于 512 MB 的文件不显示（文件夹不受限，见 AppConfig）；
  .iso 后缀文件不显示（不分大小写，文件夹不受限）
- 空文件夹处理：列表里自动隐藏（查详情按 count 判断，会话级缓存，
  剔除带淡出折叠动画）；点按先拉该目录列表走同链过滤，无可见文件
  直接 toast「无文件」不进入（内容全被过滤的「本地空」目录同样命中）；
  推入的文件页首屏为空自动弹回并提示
- 名字屏蔽词过滤：命中屏蔽词（大小写不敏感）的文件/文件夹不显示
- 长按弹窗：把该文件/文件夹的名字（可编辑改词）保存到屏蔽列表
  （与设置页屏蔽词同源）；保存后列表自动重拉，命中行淡出消失
- 点按行为：文件夹进入（空目录直接提示不进入）；视频进播放器；
  其他文件弹详情面板（类型/大小/时间，视频带播放按钮）
- 行首圆形图标：视频（v_img）/图片（thumb）/文件夹封面（fco）有服务端
  缩略图时圆形裁剪显示，加载中/失败/无缩略图回退类型图标；
  仅内存缓存不落盘（开发须知：用户文件内容不缓存到本地磁盘）
- 加密文件夹：提示使用 115 官方 App 查看
- 顶栏：汉堡按钮侧滑打开「我的」抽屉
- 列表/网格双视图（网格切换入口暂时隐藏，代码保留）
- 新建文件夹 FAB（暂时隐藏，代码保留）
- 顶栏路径行 + 统计行（暂时隐藏，代码保留）

## 视频在线播放（全屏沉浸式）

- 播放 115 转码的 m3u8（地址无扩展名，显式按 HLS 解析）；
  进入直接选最高清晰度，失败自动降档重试（档间强制间隔，
  避免触发视频网关 WAF 频控）
- 续播与进度记忆：进入时读上次进度；暂停/退出时上报，
  播完自动标记看完（失败静默）
- 播放失败时对播放地址做 HTTP 探测（状态码/Content-Type/响应摘要），
  报错文案含诊断信息并支持重试
- 手势（整屏生效，含黑边区域）：
  - 屏幕左半边上下滑调亮度（最低 10%）
  - 屏幕右半边上下滑调音量（可到静音）
  - 左右滑快退/快进（5 秒一档，单次手势累计最多 5 分钟）
- 遥控器（电视端，上述手势与触摸操作全部保留）：
  - 控件隐藏时：左/右 = 快退/快进 10 秒一档（复用 seek 指示器与
    播放态冻结逻辑，连按/长按从同一位置累计）；OK = 唤出控件并把
    焦点交给播放/暂停按钮（不直接播放/暂停，防连按抖动）；上/下
    不响应；返回键走系统默认退出页面
  - 控件可见时：播放/进度条按方向键遍历聚焦、OK 激活；
    任何按键重置 2 秒自动隐藏计时（导航中途控件不消失）
  - 进度条聚焦时加粗到 4px + 白色光晕（3 米可见），左/右 = ±5 秒
    seek（拦截按键，不走焦点遍历）
- 方向锁（右下角，电视端隐藏）：进入强制双横屏并锁定；解锁后完全跟随
  手机物理方向（竖过来变竖屏播放），再点固定当前方向；退出恢复跟随系统
- 倍速菜单（右上角，仅手机：入口透明不可见、点区域唤出；电视不显示）：
  1.0 / 1.5 / 3.0 / 5.0 倍速
- 细进度条（2px）：点按/拖动跟手 seek；seek 期间播放态冻结，
  防止 buffering 造成播放按钮闪烁；电视端行尾留 24 余量不顶屏幕右缘
  （手机端行尾有方向锁按钮自然留白）
- 无返回按钮（用户要求移除），退出走系统返回手势/遥控器返回键
- 控件 2 秒无操作自动隐藏；暂停期间常驻；播放中保持屏幕常亮
  （暂停时解除，允许系统熄屏省电）

## 我的（侧边抽屉）

- 用户信息头部：头像、用户名、年度会员认证图标、会员服务到期时间
  （中文年月日）、存储使用方块点阵（行尾与到期行对齐）
- 菜单：设置、关于；底部退出（带确认）
- 未登录时经登录页扫码进入

## 设置

- 主题配色：flex_color_scheme 内置方案列表（约 50 套，参考 varus）；
  点击弹窗选择（方案名 + 4 色圆点预览 + 选中勾），切换全局即时生效，
  持久化保存（ghost.scheme）
- 界面字体：Montserrat（中文回退微软正黑体）/ 系统字体，弹窗二选一，
  全局即时生效，持久化保存（ghost.font）
- 名字屏蔽词：换行/英文逗号/中文逗号分隔输入，大小写不敏感去重，
  对文件列表全局生效（仅本机保存）；文件页长按行可直接把名字存入

## 底层与网络（lib/network、lib/session）

- Open115Client：业务接口全局限速（串行队列 + 最小间隔 500ms，
  防平台频率控制 405）；405 自动冷却退避重试一次
- 读接口 2 秒结果缓存 + 在途去重（连点刷新只发一次真实请求）；
  写操作成功后整体失效读缓存
- 40140125/40140126 自动单飞刷新 token 并重放请求
- API 与视频流统一 User-Agent，避免 WAF 按请求特征拦截
- 扫码长轮询 35 秒超时（对齐服务端 30 秒长轮询）
