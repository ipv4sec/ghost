# 妖妖舞（Ghost）

115 网盘第三方客户端（Flutter）。**同一 APK 同时运行在手机与 Android TV**：
电视上自动切换为深色媒体中心界面，手机保持经典文件管理器界面。
基于 115 生活开放平台（open.115.com）接口构建，账号凭证与本地设置保存在本机，
并自动备份到外部存储根目录隐藏文件 `.ghost.json`，卸载重装后可自动恢复。

> 功能细节与实现说明见 [docs/FEATURES.md](docs/FEATURES.md)。

## 手机版功能

### 文件浏览（主页）

- 浅色列表 / 网格双视图；点文件夹进入、返回手势回上级；主页根目录「再按一次返回退出」
- 列表分页（每页 50 条，滚动到底自动加载）；下拉刷新，连点合并去抖
- 本地过滤：小于 512 MB 的文件不显示（文件夹不受限）、`.iso` 不显示
- 空文件夹自动隐藏；点进空目录先预检，无可见文件直接 toast「无文件」不进入
- 屏蔽词过滤：命中屏蔽词（大小写不敏感）的文件/文件夹不显示
- **长按操作菜单：剪切（到目标目录点粘贴栏完成移动）/ 删除（移入 115 回收站，
  行内收起动画）/ 重命名**；网格长按弹详情面板
- 点按行为：文件夹进入、视频进播放器、其他文件弹详情面板（类型/大小/时间）
- 行首圆形缩略图（视频/图片/文件夹封面，仅内存缓存不落盘）
- 加密文件夹提示使用 115 官方 App 查看
- 顶栏：**单击进云下载页、双击进搜索页**；汉堡按钮侧滑打开「我的」；
  右上角三个点排序（名称/大小/上传时间/修改时间，点当前项切换升降序，全局持久化）

### 全盘搜索

- 关键词全盘搜索：500ms 防抖自动搜索，回车提交并记入历史（最多 10 条，可清空）
- 筛选 chips：全部 | 文件 | 文件夹 | 音频 | 图片 | 视频
- 结果屏蔽词过滤；结果行与文件页同款，视频可直接播放
- 空态区分：未找到 / 该类型无结果 / 均被屏蔽词过滤

### 云下载（离线任务）

- **系统点击 magnet: 链接可直接唤起本应用**（冷启动 + 热启动都支持），
  落地页确认后提交，可复制链接
- 支持 HTTP(S)/FTP/磁力/电驴链接，换行分隔可批量
- 任务列表：默认 5 条、「加载更多」逐次 +5；有进行中任务时每秒轮询，
  全部结束自动停止
- 任务行状态圆底图标 + 百分比；卡住不动超 1 分钟按失败态展示
- 左滑删除任务；点击已完成任务跳转其保存位置
- 「云下载后自动打开」开关：提交后盯住任务，完成自动打开保存位置

### 视频在线播放（全屏沉浸式）

- 播放 115 转码 m3u8；进入直接选最高清晰度，失败自动降档重试
- 续播与进度记忆；播完自动标记看完；播放失败带诊断信息可重试
- 手势：左半屏上下滑调亮度、右半屏上下滑调音量、左右滑快退/快进
- 方向锁：进入强制横屏，解锁后完全跟随物理方向
- 倍速菜单：1.0 / 1.5 / 3.0 / 5.0
- 细进度条拖动 seek；控件 2 秒无操作自动隐藏；播放中屏幕常亮

### 我的与设置

- 侧边抽屉：头像、用户名、会员图标与到期时间、存储使用点阵；设置、关于、退出（带确认）
- 主题配色：约 50 套方案即时切换，持久化保存
- 界面字体：Montserrat / 系统字体
- AppID 本地覆盖（留空用内置）；名字屏蔽词管理
- 备份与恢复：`.ghost.json` 状态查看、立即备份、删除备份、存储授权入口

## 电视版（Android TV）功能

### 电视首页

- Jellyfin 风格深色媒体中心：顶栏时钟 + 设置齿轮；页顶路径面包屑
- 「文件夹」区（4 列横卡）+「文件」区（5 列竖卡，类型图标 + 名称 + 尺寸/扩展名角标），
  空区块自动消失；根目录一次请求即出全部内容
- D-pad 聚焦：蓝描边 + 光晕 + 聚焦居中滚动跟随，初始聚焦首卡
- 点文件夹进电视文件夹页，点视频直接进播放页；返回键双击退出
- 全局文字放大 1.2 倍（3 米观看距离）；整页缩放系数 0.85 一处可调

### 电视文件夹页

- 与首页同款深色卡片网格；顶部路径面包屑，祖先段可点跳回
- 进入目录 / 回上级自动聚焦首行；接近底部自动翻页
- 长按（遥控器 OK 长按）把文件/文件夹名字加入屏蔽列表

### 遥控器播放

- 控件隐藏时：左/右 = 快退/快进 10 秒一档；OK = 唤出控件并聚焦播放键
- 控件可见时：方向键遍历聚焦、OK 激活；进度条聚焦时 ±5 秒 seek（加粗 + 光晕）
- 任何按键重置 2 秒控件自动隐藏计时

### 遥控器适配细节

- LEANBACK_LAUNCHER 电视桌面入口 + TV banner 横幅图标
- 全局焦点高亮（主题色 14% 透明度），手机触摸模式不显示、观感不变
- 登录页二维码重试按钮自动聚焦；配色/字体弹窗聚焦当前选中项
- 退出登录、删除备份等确认弹窗默认聚焦「取消」，防误触

## 双端通用

- 扫码授权登录（开放平台设备码 + PKCE）；token 自动刷新（单飞锁）；
  凭证失效自动回登录页
- 授权与设置自动备份 `.ghost.json`（登录/刷新/设置变更时写入，原子写），
  重装后静默恢复
- 网络层：全局限速 500ms 防平台频控（405 自动退避重试）；读接口 2 秒缓存 +
  在途去重；Android 走 Cronet 绕开 115 云盾 WAF 的 TLS 指纹拦截
- 手机 APK 直接装到电视即可，无需单独构建版本
